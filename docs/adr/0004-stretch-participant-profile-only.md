# 只拉伸参与者五维气韵

算法版本 `1.0.3` 起，只对参与者完成答题后得到的五维气韵执行逐轴拉伸；`data.js` 和浏览器本地覆盖中的歌曲参数直接作为最终坐标。这个不对称处理让歌曲参数所写即所得，也避免后台调参时还要推算一次隐藏变换；距离、相似度和排序公式保持不变。

## Consequences

同一份答案在 `1.0.2` 与 `1.0.3` 下可能得到不同的契合歌曲和相似度，历史报告必须通过 `algorithmVersion` 区分。使用种子 `algorithm-1.0.3-review` 对同一批 100,000 份均匀模拟答案复算后，最高第一契合率由 `7.72%` 变为 `5.55%`，从未成为第一契合歌曲的歌曲由 6 首变为 4 首，第一名并列由 1,222 次变为 582 次；全部 100 首歌曲仍至少进入过一次前五。
